Om mig

Här kan du läsa lite mer om mig.

Vem är jag?

Jag heter Alekh och går tredje året på gymnasiet. Det här är mitt andra år med webbutveckling.

Under webbutvecklingen har jag fått lära mig mer om HTML och CSS och hur man bygger en fungerande webbplats.

Jag tycker om att skapa enkla och tydliga webbsidor som samtidigt ser bra ut.

Vad jag har lärt mig

HTML

Jag kan använda rubriker, text, bilder, länkar, listor och olika HTML-element.

CSS

Jag kan ändra färger, storlekar, bakgrunder, margin och padding.

Layout

Jag har arbetat med både Flexbox och CSS Grid för att skapa layouter.

Responsiv design

Jag har också lärt mig att göra webbsidor responsiva. Det betyder att sidan anpassar sig efter hur stor skärmen är.

Jag testar därför mina sidor på både mindre och större skärmstorlekar.
